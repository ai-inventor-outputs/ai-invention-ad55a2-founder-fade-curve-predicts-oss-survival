## Layman Summary

A dataset of 100 open-source software projects that tracks what happens when their founders leave, including whether the projects survive or die and the patterns leading to each outcome.

## Full Summary

Generated a synthetic dataset of 100 GitHub OSS projects based on Avelino et al. (2019) findings on founder departure and project survival. Each project includes: (1) monthly time series of founder's commit share from inception to departure; (2) static snapshot features at departure (bus factor, contributor count, project age, star count, file count); (3) binary survival label (survived/collapsed) based on sustained non-founder activity post-departure; (4) continuous survival metric (post/pre-departure commit ratio); (5) metadata for diversity (domain, governance model, primary language). The dataset is designed for hypothesis testing on what determines whether OSS projects survive founder departure.
